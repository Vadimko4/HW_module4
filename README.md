# Проект "HW_module4"

## Описание:

Проект является серией домашних заданий к модулю 4 курса "Питон-разработчик" по теме ООП.

### Редакция от 28.03.2025 - реализация домашнего задания 14.1:
Созданы классы Product и Category.

Класс Product имеет следующие поля:
название (name),
описание (description),
цена (price),
количество в наличии (quantity)

Класс Category:
название (name),
описание (description),
список товаров категории (products)
Также для класса Category есть два атрибута класса. Доступ к ним у каждого объекта класса, и в них 
хранится общая информация для всех объектов. Эти атрибуты хранят в себе количество категорий и количество товаров.
Атрибуты класса заполняются автоматически при инициализации нового объекта.

У обоих классов реализованы конструкторы.

В качестве дополнительного задания реализовано считывание объектов из json файла

### Редакция от 06.04.2025 - реализация домашнего задания 16.1:
От базового класса Product написаны дочерние классы Smartphone и LawnGrass
Они дополнены своими атрибутами, которых нет в родительском классе
Для них реализован магический метод __add__, не позволяющий складывать с объектами данных классов объекты других классов
Так же в классе Category дописана защита от добавления в список продуктов категории чего-то другого кромоме объектов
классов Product, Smartphone или LawnGrass

### Редакция от 07.04.2025 - реализация домашнего задания 16.2:
Реализовано множественное наследование. 
Создан абстрактный класс BaseProduct, в котором прописаны все главные абстрактные методы, которые должны быть у потомков.
Так же написан миксин класс PrintMixin, со своим конструктором и __repr__ методом.
__repr__ метод возвращает строку: объектом какого класса является создаваемый объект и с какими характеристиками он 
создан.
В конструкторе результат метода __repr__ выводится в консоль. Класс Product теперь является потомком абстрактного класса
BaseProduct и PrintMixin, а его конструктор переписан так, чтобы при создании его экземпляров выводился результат 
метода __repr__
Классы «Смартфон» и «Трава газонная» остаются наследниками класса Product и тем самым наследуют все свойства 
абстрактного класса.
