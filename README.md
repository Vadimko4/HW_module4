# Проект "HW_module4"

## Описание:

Проект является серией домашних заданий к модулю 4 курса "Питон-разработчик" по теме ООП.

Редакция от 28.03.2025 - реализация домашнего задания 14.1:
Созданы классы Product и Category.

Класс Product имеет следующие поля:
название (name),
описание (description),
цена (price),
количество в наличии (quantity)

Класс Category:
название (name),
описание (description),
список товаров категории (products)

Функции проекта оттестированы в различных условиях.

Покрытие проекта тестами 90%
В репозиторий добавлен обновлённый файл с отчётом в html

Проект проверен линтерами

## Установка:

1. Клонируйте репозиторий:
```
git clonegit@github.com:Vadimko4/HW_module4.git
```
или
```
git clone https://github.com/Vadimko4/HW_module4.git
```

2. Установите зависимости:
```
poetry install
```
3. Ознакомьтесь с инструкцией в файле .env.example и донастройте окружение (введите свои API_KEY)

## Использование:

Запустите на выполнение файл main.py
