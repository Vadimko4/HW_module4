# Проект "HW_module4"

## Описание:

Проект является серией домашних заданий к модулю 4 курса "Питон-разработчик" по теме ООП.

### Редакция от 28.03.2025 - реализация домашнего задания 14.1:
Созданы классы Product и Category.

Класс Product имеет следующие поля:
название (name),
описание (description),
цена (price),
количество в наличии (quantity)

Класс Category:
название (name),
описание (description),
список товаров категории (products)
Также для класса Category есть два атрибута класса. Доступ к ним у каждого объекта класса, и в них 
хранится общая информация для всех объектов. Эти атрибуты хранят в себе количество категорий и количество товаров.
Атрибуты класса заполняются автоматически при инициализации нового объекта.

У обоих классов реализованы конструкторы.

В качестве дополнительного задания реализовано считывание объектов из json файла
